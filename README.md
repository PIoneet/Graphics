Shadow Step 8 정리하기

Ray Tracing에서 그림자를 구현하기 위해서 모니터에서 광선이 충돌한 지점을 기준으로 Ray를 한번 더 쏴줬다. 
이걸 ShadowRay라고 선언해서 hit.point에 1e-4f 정도 앞으로 나간 지점에서 조명을 향해 뻗어나가는 광선이다. 
지금 현재 오브젝트 위에 있는 상황이라 조금 떨어진 위치에서 광선이 나가도록 구성되어있다. 

이 광선이 충돌했다면 가려저있는 위치라는 거니까 그림자 즉 엠비언트 색상만 반환하고 그렇지 않은 경우에는 
디퓨저항 스페큘러항까지 게산해서 반환하도록 했다. 이를 통해 그림자가 구현되었다.
